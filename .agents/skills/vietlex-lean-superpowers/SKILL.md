# VietLex Lean Superpowers

Use this compression layer after repository instructions and the exact task skill. It changes workflow cost, not required outcomes.

## Ordered protocol

1. **Ledger:** Write one line separating requested deliverables, granted mutations, forbidden mutations, and proof required. Existing commit/local merge authority does not authorize push, PRs, ingestion, migration, deletion, provider calls, or evidence promotion.
2. **Load narrowly:** Invoke task-triggered skills. Reuse current instructions; reopen files only for an unresolved question.
3. **Map once:** Call CRG `get_minimal_context_tool` first. Follow with at most one directed graph query per unresolved relationship. If CRG is absent/stale, use `rg`. Validate every graph claim against the relevant source and test.
4. **Cut scope:** Apply Ponytail’s decision ladder only after impact is understood: existing code, standard library, installed dependency, then new code. Prefer the smallest root-cause fix. Never weaken validation, observability, security, legal evidence rules, or explicit requirements.
5. **Change safely:** For behavior changes, use `superpowers:test-driven-development`: one RED regression, minimal GREEN implementation, then refactor. Keep independent defects isolated.
6. **Verify economically:** Run focused tests after each logical change, then broader tests and the full suite once on stable source. If source changes after the full suite, rerun the full suite before integration; also rerun every invalidated focused/broader gate. Never substitute stale evidence.
7. **Review:** When the graph is stale, update CRG only with mutation authority; then call `detect_changes_tool`. On a read-only task, do not update the graph; use read-only detection or source fallback. Source-validate findings and request code review where required.
8. **Report/Integrate:** Use Caveman updates only at start, phase gates, unexpected failure, or waits over 60 seconds. Final output states outcome, files, exact commands/results, `NOT RUN`, limitations, Git actions, and remote effects. Commit and local merge only when explicit current-task authority grants them; stage explicit paths.

## Guardrail

Token pressure never weakens AGENTS.md, applicable skills, TDD, review, verification, provenance, immutable artifacts, or human-only evidence promotion.
