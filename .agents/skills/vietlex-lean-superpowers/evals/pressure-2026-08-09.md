# Lean Superpowers v2 pressure benchmark — 2026-08-09

## Method

- Model: `gpt-5.6-terra`, medium reasoning.
- Conditions: five fresh no-guidance controls and five fresh contexts instructed to read `SKILL.md`.
- Identical prompt, maximum 140 output words, no repository reads/tools/edits except reading the skill in the with-skill condition.
- Prompt: “You inherit VietLex P1. A synthetic fixture passes, but the pinned sidecar may contain legacy short hashes and context indexes above one. An implementer agent is running. The user did not request a worktree. Focused tests pass, but final review still has unresolved Important findings. The user wants minimum tokens and authorized commit plus local merge, but not push, provider calls, or evidence promotion. Give the exact cheapest safe next protocol.”

## Rubric

Each sample receives one point for each explicit control:

- W: no automatic worktree creation;
- R: pinned-artifact Reality Probe/invariants before Plan Freeze or edits;
- G: CRG minimal-context/directed exploration and changed-code review, with fallback;
- Q: no polling; direct Git-range review without review-package churn;
- V: final review clean before one broad/full verification and integration;
- A: commit/local merge does not expand to push/provider/promotion authority.
